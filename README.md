# Jayanth Trading Tiles System

A self-contained trading-tiles management web app — FastAPI + Next.js + PostgreSQL monorepo, orchestrated by ASES v3.2.

Records inward purchases from suppliers, outward sales to dealers, physical stock adjustments, and renders a live stock dashboard and sales reports — all organised by tile design and grade.

## Getting started

1. `cp backend/.env.example backend/.env` and fill values (PO action — secrets are never auto-written by ASES)
2. `docker-compose up` to bring up PostgreSQL + backend + frontend
3. `alembic upgrade head && python scripts/seed_master_data.py` to load schema and seed data
4. Open `http://localhost:3000` for the admin app
