## `backend/src/domain/auth.py`
**Module:** M-008 · **Layer:** domain
**Purpose:** Pure domain functions for password hashing and JWT lifecycle. No I/O.

### Functions

#### `get_password_hash()`
bcrypt hash via passlib CryptContext.
- **Inputs:** `plain_password: str`
- **Outputs:** `hashed: str`

#### `verify_password()`
Constant-time bcrypt comparison.
- **Inputs:** `plain_password: str`, `hashed_password: str`
- **Outputs:** `valid: bool`

#### `create_access_token()`
Signs a JWT (HS256) with sub, role, exp. Default TTL = 8 hours per DS-018.
- **Inputs:** `data: dict`, `expires_delta: timedelta | None`
- **Outputs:** `token: str`
- **Raises:** `ValueError` if SECRET_KEY not configured

#### `decode_access_token()`
Decodes and validates a JWT. Returns None on expiry/malform — never raises.
- **Inputs:** `token: str`
- **Outputs:** `payload: dict | None`

### Interfaces
- **Exports:** `get_password_hash`, `verify_password`, `create_access_token`, `decode_access_token`
- **Expects:** `passlib[bcrypt]`, `python-jose`

### Dependencies
_(none — pure functions)_

## `backend/src/main.py`

**Purpose:** Mount 6 new V2 routers. Add `dependencies=[Depends(get_current_user)]` to all 11 V1 router mounts and 5 new V2 router mounts. `auth.router` remains open.

```python

# After (V2):
app.include_router(auth.router, prefix="/api/v1")          # open
```

## `backend/src/domain/invoice.py`
**Module:** M-011 · **Layer:** domain
**Purpose:** Pure arithmetic functions for invoice computation. No I/O.

### Functions

#### `compute_line_total(quantity, unit_price)`
Returns `Decimal(quantity) * unit_price` rounded 2dp ROUND_HALF_UP.
- **Raises:** `ValueError` if quantity ≤ 0 or unit_price < 0

#### `compute_invoice_total(line_totals)`
Returns `sum(line_totals)` rounded 2dp.
- **Raises:** `ValueError` if list is empty

#### `compute_invoice_status(total_amount, paid_amounts)`
`paid_sum == 0 → 'PENDING'` | `paid_sum >= total → 'PAID'` | else `'PARTIAL'`

#### `generate_invoice_number(invoice_date, sales_header_id)`
Returns `'INV-{YYYYMMDD}-{sales_header_id:05d}'` — deterministic, unique by FK constraint.

### Interfaces
- **Exports:** all 4 functions above
- **Expects:** `decimal.Decimal`, `datetime.date`

### Dependencies
_(none — pure functions)_

## New Decisions Summary

| ID | Title |
|---|---|
| DS-018 | JWT auth (python-jose + passlib bcrypt, 8h TTL, no refresh tokens) |
| DS-019 | Role enum on tbl_user_master (STAFF/VERIFIER/SUPERVISOR, no roles table) |
| DS-020 | TD-008 closed — DS-015 advisory lock already serializes first-row inserts |
| DS-021 | reportlab (PDF) + openpyxl (XLSX) for exports via StreamingResponse |
| DS-022 | Active price = latest effective_from ≤ today; unit_price snapshotted on invoice line |
| DS-023 | Invoices created on-demand by SUPERVISOR (not auto on sales save); UNIQUE per sale |
