## Database Migration

**Migration:** `backend/db/migrations/versions/0004_v2_auth_pricing_tables.py`

### New Tables

```
tbl_user_master
  id, username (UNIQUE), password_hash, role ENUM(STAFF|VERIFIER|SUPERVISOR),
  is_active, created_at TIMESTAMPTZ

tbl_price_master
  id, design_id FK, grade_id FK,
  unit_price NUMERIC(10,2), effective_from DATE, is_active,
  created_at TIMESTAMPTZ
  UNIQUE(design_id, grade_id, effective_from)

tbl_invoice_header
  id, invoice_number VARCHAR(30) UNIQUE,
  sales_header_id FK UNIQUE,   ← one invoice per sale
  invoice_date, total_amount NUMERIC(12,2),
  status CHECK(IN 'PENDING','PARTIAL','PAID'),
  created_at TIMESTAMPTZ

tbl_invoice_line
  id, invoice_header_id FK, sales_line_id FK UNIQUE,
  design_id, grade_id, quantity, unit_price NUMERIC(10,2), line_total NUMERIC(12,2),
  created_at TIMESTAMPTZ

tbl_payment
  id, invoice_header_id FK, payment_date,
  amount NUMERIC(12,2) CHECK(> 0), notes TEXT,
  created_at TIMESTAMPTZ
```
